# Catch me up

Read before you answer. Never answer this from memory of the conversation.

1. **The last few days.** The most recent pages in `Today/`. What was happening and where it
   got to.
2. **Live work.** Every page in `Projects/`. For each, the last thing that happened and what
   it is waiting on.
3. **Waiting.** Anything in `Inbox/` that has not been dealt with.
4. **Recent decisions.** Anything in `Decisions/` from the last fortnight.

Then say it back in plain sentences, shortest useful version, in this order:

- **What is live** — being worked on now.
- **What is waiting** — on them, or on somebody else. Say which.
- **What is stuck** — no movement, and why, if the brain knows.
- **What has gone quiet** — a project with nothing written against it for a fortnight or more.
  Say so plainly and ask whether it is still on.

Rules while you do it:

- Never say something is not there without looking under every name it could have.
- If a fact is undated, say you do not know how current it is.
- Never invent progress. "Nothing written since 14 August" is a real answer.
- Do not turn it into a list of questions. Say where things stand, then stop.

Finish by clearing what you can: anything in `Inbox/` that obviously belongs somewhere, file it
and say you did.
